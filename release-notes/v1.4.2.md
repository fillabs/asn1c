# v1.4.2 Release Notes

## Changes since v1.4 (2026-03-06)

### Highlights
- Hardened integer decoding across OER/UPER/APER, including rejection of invalid zero-length INTEGER bodies.
- Improved PER constraint handling for character string types and constrained INTEGER edge cases.
- Expanded `-fprefix` coverage to additional generated symbols and anonymous typedef scenarios.
- Fixed circular-reference and deeply nested type generation issues affecting complex specifications.
- Addressed security vulnerabilities and code-scanning findings, including formatting-related fixes and decoder hardening.

### Notable fixes and improvements
- Fixed zero-length INTEGER body handling in OER, UPER, and APER decoders (PR #510).
- Fixed compiler warnings including misleading indentation and an unused function (PR #508).
- Fixed PER SIZE constraints for UTF8String and other character string types (PR #494).
- Fixed `-fprefix` application for anonymous typedef names and generated member symbols (PRs #498, #477).
- Fixed circular include handling for deeply nested and circularly referenced generated types (PR #486).
- Hardened APER constrained INTEGER decoding against determinant and offset underflow (PR #481).
- Fixed CBOR regression coverage and test updates (PR #505).
- Addressed multiple code-scanning alerts involving formatting function argument types (PRs #499, #500, #501, #502, #503, #504).

### Security
This release includes security-related hardening and explicitly addresses reported security vulnerabilities and code-scanning findings.
